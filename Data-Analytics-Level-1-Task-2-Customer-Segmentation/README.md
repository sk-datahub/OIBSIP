Task 2 — Customer Segmentation Analysis
Objective

Perform customer segmentation analysis to identify different groups of customers based on their purchasing behaviour and develop suitable marketing strategies for each segment.

Tools & Technologies
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
Jupyter Notebook
Analysis Performed
Customer transaction data inspection and cleaning
Recency, Frequency and Monetary (RFM) analysis
Average Purchase Value calculation
Customer Frequency analysis
Customer Lifetime Value analysis
Feature scaling using StandardScaler
Elbow Method for selecting the optimal number of clusters
Customer segmentation using K-Means clustering
Cluster size analysis
Customer cluster profiling
Scatter plot visualizations
Identification of different customer types
Marketing recommendations for each customer segment
Methodology

RFM-based behavioural features were used to understand customer purchasing patterns. The selected features were standardized using StandardScaler and K-Means clustering was applied to group customers with similar behaviour.

Dataset

The analysis uses the customer_transactions.csv dataset.

Files
Task_2_Customer_Segmentation.ipynb — Jupyter Notebook containing the complete customer segmentation analysis
customer_transactions.csv — Customer transaction dataset
customer_segments.csv — Final customer cluster assignments and segment information
Key Outcome

The analysis identifies distinct customer segments based on purchasing behaviour. These segments can help businesses create targeted marketing campaigns, improve customer retention, and allocate resources more effectively.

Conclusion

Customer segmentation provides valuable insights into customer behaviour. Businesses can use the identified segments to design personalized promotions, retain high-value customers, encourage repeat purchases, and improve overall customer engagement.
