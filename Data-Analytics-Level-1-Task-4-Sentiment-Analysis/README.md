Task 4 — Sentiment Analysis
Objective

Perform sentiment analysis on text data to classify customer/user opinions into different sentiment categories and evaluate machine learning models for sentiment prediction.

Tools & Technologies
Python
Pandas
Scikit-learn
NLTK
Matplotlib
Seaborn
Jupyter Notebook
Analysis Performed
Loaded and inspected the sentiment dataset
Analysed sentiment class distribution
Cleaned text by converting it to lowercase
Removed punctuation and unnecessary characters
Performed text preprocessing and tokenization
Converted text into numerical features using TF-IDF
Split the dataset into training and testing sets using an 80/20 split
Trained a Naive Bayes classification model
Trained a Logistic Regression classification model
Evaluated model performance using accuracy, precision, recall, and F1-score
Created confusion matrices for model evaluation
Visualized sentiment distribution
Generated WordClouds for sentiment categories
Analysed misclassified examples
Compared the performance of both models
Dataset

The analysis uses the sentiment_data.csv dataset.

Files
Task_4_Sentiment_Analysis.ipynb — Jupyter Notebook containing the complete sentiment analysis
sentiment_data.csv — Sentiment dataset
Key Outcome

The analysis identifies sentiment patterns in the text data and evaluates machine learning models for automatically classifying user opinions.

Conclusion

Sentiment analysis can help businesses understand customer opinions at scale. The model results can be used to identify positive, neutral, and negative feedback and support better customer-service and business decisions.
