Task 3 — Data Cleaning
Objective

Clean and preprocess a retail dataset by identifying and resolving data quality issues such as missing values, duplicate records, inconsistent formatting, incorrect data types, and outliers.

Tools & Technologies
Python
Pandas
NumPy
Jupyter Notebook
Data Quality Checks
Checked dataset shape and structure
Identified missing values
Checked for duplicate records
Reviewed data types
Identified inconsistent formatting
Checked for range and value anomalies
Detected potential outliers using the IQR method
Data Cleaning Performed
Handled missing values using appropriate imputation strategies
Removed duplicate records
Standardized inconsistent categorical values
Converted columns to appropriate data types
Handled invalid or anomalous values
Detected and evaluated outliers using the Interquartile Range (IQR) method
Compared the dataset before and after cleaning
Dataset

The analysis uses the messy_retail_data.csv dataset.

Output Files
Task_3_Data_Cleaning.ipynb — Jupyter Notebook containing the complete data cleaning process
messy_retail_data.csv — Original dataset containing data quality issues
cleaned_retail_data.csv — Cleaned dataset
before_after_summary.csv — Summary comparing the dataset before and after cleaning
Key Outcome

The cleaning process improves data quality and prepares the dataset for reliable analysis and further data-driven applications.

Conclusion

Proper data cleaning is an essential step before performing analysis or building machine learning models. The cleaned dataset contains standardized values, corrected data types, handled missing values, and reduced data quality issues.
